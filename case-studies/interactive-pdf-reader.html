Interactive PDF Reader

A focused document-reading experience built around Adobe’s PDF Embed API and smarter navigation.

The problem

Long documents are easier to use when the interface supports focused reading and quick movement through important sections.

My approach

I kept the interface focused on document context and navigation so the API integration served the reading experience instead of distracting from it.

What I built

An interactive reader prototype with Adobe PDF Embed API integration and a distraction-free document flow.

Challenges and decisions

The main challenge was balancing an external document viewer with a simple product experience. I shaped the surrounding interface around the reader rather than adding unnecessary controls.

Outcome

Selected for the second round of Adobe’s Connecting the Dots challenge. Additional usage and completion data is available on request.
